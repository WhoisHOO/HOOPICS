# HOOPICS

<img src="HOO_Logo.jpg" alt="HOO 로고" width="96" align="right" />

**흐릿한 이미지를 내 화면 크기에 꼭 맞게, AI로 선명하게 키워 드립니다.** 이미지를 끌어다 놓고 어디에 쓸지
(내 화면, 노트북, 모니터, 스마트폰)만 고르면 됩니다.

Windows 10/11 · 설치할 것 없음 · 모든 처리는 내 PC 안에서 · [MIT 라이선스](./LICENSE) ·

## 사용 방법

1. 이 페이지 위쪽의 **Code → Download ZIP**을 눌러 내려받고, 원하는 곳에 압축을 풉니다.
   Git이나 Python은 필요 없습니다.
2. **`start.bat`** 를 더블클릭합니다. 이미지를 `start.bat` 위로 끌어다 놓아도 됩니다.
3. 어디에 쓸지 고르고 **변환 시작**을 누릅니다.

결과는 원본과 같은 폴더에 `원본이름_2560x1600.png` 처럼 저장됩니다("배율로 키우기"는 `원본이름_x2.png`).
기존 파일은 절대 덮어쓰지 않고, 다시 만들면 `원본이름_2560x1600 (2).png` 처럼 번호가 붙습니다.

**처음 한 번만** AI 엔진과 모델(약 36MB)을 내려받습니다. 마이크로소프트의 ONNX Runtime, DirectML, Visual C++
런타임을 마이크로소프트 원본 그대로 묶은 것과, Philip Hofmann이 만든 [NERVE 모델](docs/MODELS.md) 두 개입니다.
모두 HOOPICS와 함께 올려 두었습니다. 내려받은 파일과 그 안의 파일 하나하나를 SHA-256 값으로 확인한 뒤 쓰고,
그다음부터는 인터넷 없이도 동작합니다.

> **`start.bat` 이 실행되지 않나요?** Windows는 인터넷에서 받은 파일에 표시를 붙이고, 스마트 앱 컨트롤이 켜져 있으면
> 이 표시가 있는 `start.bat` 을 막습니다. 압축을 푼 폴더를 지우고, 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러
> **속성** → **차단 해제** 를 체크하고 **확인** 을 누른 뒤 다시 압축을 풀어 주세요. "Windows의 PC 보호" 창이 뜨면
> **추가 정보 → 실행** 을 누르면 됩니다.

## 고를 수 있는 것

| 항목 | 설명 |
|---|---|
| **내 화면 (자동)** | 연결된 모든 화면의 실제 해상도를 알아내서 화면마다 이미지를 하나씩 만듭니다. *끝나면 바탕화면으로 설정* 을 켜면 각 화면에 맞는 이미지가 바탕화면으로 바로 적용됩니다. |
| **노트북 / 모니터 / 스마트폰·태블릿** | 자주 쓰는 해상도 모음: HD~5K, 16:10, 3:2, 21:9·32:9 울트라와이드, 맥북, 갤럭시, 아이폰, 아이패드 |
| **배율로 키우기** | 비율은 그대로 두고 2배, 3배, 4배로 키웁니다. |
| **직접 입력** | 가로 × 세로를 16~16384 사이에서 마음대로 정합니다. |
| **꽉 채우기 / 전체 보이기** | *꽉 채우기* 는 화면 비율에 맞춰 가장자리를 고르게 잘라냅니다(Windows 배경 "채우기"와 같음). *전체 보이기* 는 그림 전체를 보여 주고 남는 공간은 흐리게 처리한 같은 그림으로 채웁니다. |
| **그림 종류** | 애니메이션·일러스트(기본)와 실제 사진 중에서 고릅니다. 모델 설명은 [docs/MODELS.md](docs/MODELS.md)(영어)에 있습니다. |

- 여러 이미지나 폴더를 통째로 넣으면 같은 설정으로 한 번에 처리합니다.
- JPG, PNG, WEBP, BMP, GIF, TIFF를 읽고 PNG(무손실) 또는 JPG로 저장합니다.
- 휴대폰으로 찍어 옆으로 누운 사진은 바로 세우고, PNG의 투명 배경은 그대로 유지합니다.
- 화면 언어는 Windows 언어 설정을 보고 한국어나 영어로 정해집니다. 오른쪽 위 버튼으로 언제든 바꿀 수 있습니다.

## 필요한 것

- Windows 10 또는 11 (64비트). HOOPICS가 쓰는 PowerShell 5.1과 WPF는 Windows에 기본으로 들어 있습니다.
- DirectX 12를 지원하는 그래픽카드(NVIDIA, AMD, Intel)가 있으면 빠릅니다. 없거나 처리 도중 그래픽카드에 문제가 생기면
  CPU로 마저 처리합니다. 이때는 시간이 더 걸립니다.

## 이전 버전

HOOPICS 0.1.x는 Real-ESRGAN 모델로 그림을 키웠습니다. 그중 "더 선명한 애니메이션용" 모델은 0.2보다 윤곽선이 더
또렷하지만, 학습된 가중치의 라이선스가 밝혀져 있지 않고 애니메이션 모델의 학습 데이터도 공개되지 않았습니다.
HOOPICS 0.1.2는 [릴리스 페이지](https://github.com/WhoisHOO/HOOPICS/releases/tag/v0.1.2)에서 계속 받을 수 있고,
새 기능은 더 이상 추가되지 않습니다.

## 자주 묻는 질문

**변환이 실패해요.** 엔진 파일이 손상되면 HOOPICS가 알아서 다시 내려받습니다. 그래픽카드 문제는 HOOPICS가 알아서 CPU로 넘어가므로
실패하지 않고 느려지기만 합니다.
느리다면 NVIDIA/AMD/Intel 홈페이지에서 최신 그래픽 드라이버를 설치해 보세요.

**결과는 어디에 저장되나요?** 원본 이미지가 있는 폴더입니다. 끝나면 나오는 **결과 폴더 열기** 버튼으로 바로 열 수 있습니다.
원본 폴더에 저장할 수 없으면 `사진\HOOPICS` 폴더에 저장합니다.

**이미지가 너무 작다고 나와요.** AI 확대는 최대 16배까지입니다. 그보다 큰 확대가 필요하면 더 큰 원본을 써 주세요.

**인터넷으로 이미지가 전송되나요?** 아니요. 모든 처리는 내 PC 안에서만 이루어집니다. 인터넷은 처음 한 번 AI 엔진과 모델을 내려받을 때만 씁니다.
ONNX Runtime의 사용 통계 기능도 꺼 둡니다. 자세한 내용은 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md#engine-runtime)에 있습니다.

**지우고 싶어요.** 압축을 푼 폴더를 지우면 끝입니다. 언어 설정을 바꾼 적이 있다면 `%APPDATA%\HOOPICS` 폴더도 지우세요.
